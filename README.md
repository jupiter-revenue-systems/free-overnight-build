# Plan It at 10 PM, Done by 7 AM

A planner that turns one big task into a master prompt, a run checklist for Claude Code, and a morning report. You review finished work, not a blank page.

**The promise:** your first overnight build, finished while you sleep.

By Ekai Stone, Jupiter Revenue Systems.

## Who it's for

Coaches, agency owners and creators who don't have enough hours in the day for the big tasks.

## What's inside

- `START_HERE.md`: instructions written to the AI. It interviews you and writes your plan for the night.
- `templates/master-prompt.md`: the layout for the prompt Claude Code runs overnight.
- `templates/run-checklist.md`: what to do before bed, step by step.
- `templates/morning-report.md`: the report the agent fills in, plus the second check.

## How to use it

1. Pick one big task made of files. Nothing live. Nothing that sends, publishes, spends or deletes.
2. Open a new chat in Claude, upload this pack, and send: `Read START_HERE.md and follow it exactly. I want to plan an overnight build.`
3. Answer the planner one question at a time. Save the 3 files it writes.
4. Make a copy of your project folder and work only in the copy.
5. Follow the run checklist: start Claude Code in the copy, paste the master prompt, watch the first 10 minutes, then go to bed.
6. In the morning, read the report, run the second check with a fresh agent, and decide what goes live.

## What it doesn't do

- It only builds drafts in a copy folder. It doesn't touch anything live.
- It doesn't alert you if something breaks overnight.
- It doesn't back anything up for you.
- It doesn't choose the task.

## What you need

Claude on a paid plan that includes Claude Code, and a computer that can stay on overnight.
